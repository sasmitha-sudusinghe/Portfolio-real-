## ✨ Overview

This is the source code for my **personal developer portfolio** — a fully hand-crafted, single-page application built with pure HTML, CSS, and JavaScript. No frameworks, no build tools. Just clean, fast, and beautifully designed code.

The portfolio showcases who I am, my technical skills, my academic background, and the projects I've built — with a focus on delivering a premium, interactive user experience.

**🔗 Live Site:** _(deploy link here)_

---

## 🚀 Features

- 🌗 **Light / Dark Mode** — Smooth animated theme toggle with system-level aesthetics
- 🎆 **Particle Canvas** — Interactive animated background using the HTML5 Canvas API
- ✍️ **Typewriter Effect** — Animated role cycling on the hero section
- 📊 **Animated Skill Bars** — Scroll-triggered progress bars with percentage labels
- 🕐 **Education Timeline** — Visually structured academic history
- 🃏 **Project Cards** — Glassmorphism-styled cards with live status badges
- 📬 **Contact Form** — Client-side validated contact form
- 📱 **Fully Responsive** — Mobile-first design with a hamburger nav menu
- ⬆️ **Scroll-to-Top** — Floating button with smooth scroll behavior
- ⚡ **Zero Dependencies** — No npm, no bundler, no framework overhead

## 🏃 Running Locally

No build step needed. Just open the file:

```bash
# Clone the repo
git clone https://github.com/sasmitha-sudusinghe/portfolio.git

# Open in browser
# Option 1: Double-click index.html
# Option 2: Use VS Code Live Server extension
# Option 3: Serve with npx
npx serve .
```

## 🎨 Design Highlights

- **Glassmorphism** cards with `backdrop-filter: blur()`
- **CSS Custom Properties** for seamless light/dark theming
- **Scroll-triggered animations** via `IntersectionObserver`
- **Micro-animations** on hover, clicks, and page load
- **Curated color palette** — indigo/violet accent tones
